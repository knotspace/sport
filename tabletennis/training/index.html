練習メニュー

目的を決めて、練習の質を一段上げる。

練習は「何を改善するか」を決めるところから。技術練習、フットワーク、サービス・レシーブ、実戦練習を組み合わせ、振り返りまで行いましょう。

01

基礎練習

フォア・バックの安定

フォアとバックを交互に打ち、基本姿勢と打点を崩さずに連続ラリーする練習。まずは一定コースで10球続け、安定したらテンポとコースを少しずつ変えます。

GUIDE / 01

切り替え

フォア側とバック側へ交互に送球し、身体の向きとラケット位置を素早く切り替える練習。打った後にニュートラルな姿勢へ戻ることを成功条件にします。

GUIDE / 02

ツッツキの安定

下回転のボールを同じ高さ・長さで返す反復練習。ラケット角度と打球点を一定にし、ネットミスとオーバーミスの原因を分けて記録します。

GUIDE / 03

ブロックのコース

相手のドライブをブロックし、クロスとストレートへ打ち分ける練習。大きく振らず、面の向きと打球点でコースを変える感覚を身につけます。

GUIDE / 04

下回転へのドライブ連続

下回転のボールをフォア・バックへ交互に送り、ループ気味のドライブで返す練習です。動作順は①低い姿勢で待つ②ボールの下側をこする③打球後にニュートラルへ戻る。10球中6球を安定して入れることを目標にします。よくあるミスは手だけで持ち上げること。修正はスイングを小さくし、打点を身体の前にそろえます。

GUIDE / 05
02

フットワーク

左右2点

フォア側とバック側の2点へランダムまたは交互に送球し、移動・打球・戻りを繰り返すフットワーク練習。最初はゆっくり正確に、慣れたらテンポを上げます。

GUIDE / 06

飛びつき・回り込み

フォア側へ大きく動く飛びつきと、バック側からフォアハンドへ回り込む動きを練習。打球後に体勢を立て直し、次球に備えるところまでを一連の動作にします。

GUIDE / 07

前後の動き

短いボールと深いボールを交互に送り、前後の移動と打球後の戻りを練習します。足だけを伸ばさず、重心を低く保って細かく調整します。

GUIDE / 08

ランダム対応

コースや球種を予測できない状態で返球し、判断と動き出しを鍛える練習。最初は範囲を限定し、成功率が上がったら球種・回転・テンポを追加します.

GUIDE / 09

前後左右の4点フットワーク

短いフォア・深いバック・短いバック・深いフォアの4点へランダムに送球してもらいます。動作順は①2点で正確に動く②4点へ広げる③打球後に中央へ戻る。コツは大きな一歩のあとに小さな調整歩を入れること。よくあるミスは腕だけを伸ばすこと。修正は速度を落とし、足で打点へ入る形を確認します。

GUIDE / 05
03

サービス・3球目

サービスの回転量

同じ構えから下回転・横回転・ナックルを出し分ける練習です。動作順は①トスと構えをそろえる②インパクトの位置を変える③同じコースへ10球ずつ送る。回転量だけでなく、相手のレシーブが浮くか・長くなるかも記録します。よくあるミスはフォームまで変えてしまうこと。修正は、まず同じフォームで回転を弱・中・強の3段階に分け、各段階で成功率を確認します。

GUIDE / 11

長短の打ち分け

短いサービスはネット際に2バウンドする長さ、長いサービスは相手コートの深い位置を狙います。動作順は①短い球を5球②長い球を5球③順番をランダムにして10球。コツはトス・構え・始動をそろえ、打球点と力の伝え方で長さを変えることです。よくあるミスは短くしようとしてネットにかけること。修正は、最初は台の中央を狙い、少しずつ短くしていきます。

GUIDE / 12

3球目攻撃

サービスを出したあと、相手の返球コースを決めて3球目を打つ反復練習です。動作順は①サービスを出す②決めたコースへ返球してもらう③3球目をクロスかストレートへ打つ④打球後に構え直す。10本中6本以上を狙ったコースへ入れることを目標にします。よくあるミスはサービス後に見送ってしまうこと。修正は、サービス直後に小さく戻る動きを必ず入れてから3球目へ移ります。

GUIDE / 13

サービスからの展開

サービスの種類ごとに、相手の返球を想定して次の2球まで組み立てる練習です。例として、短い下回転からツッツキを引き出す形、長い横回転からバック側へ返球させる形を作ります。コツはサービスの狙いと次球のコースをセットで決めること。よくあるミスはサービスだけを練習して次球が止まること。修正は、サービスから3球目までを1セットとして10回続けます。

GUIDE / 14

サーブ・レシーブからの展開

サーバーとレシーバーを交代しながら、サーブから4球目までを続ける練習です。動作順は①サーブの狙いを決める②レシーブを指定コースへ返す③3球目を打つ④4球目でコースを変える。よくあるミスは3球目の後に止まること。修正は、打球後の戻り位置までを1セットとして10回行います。

GUIDE / 05
04

実戦・振り返り

課題を決めたゲーム

ゲーム前に「3球目を先に攻める」「相手のバック側へ深く集める」など、1つだけ課題を決めて11点ゲームを行います。動作順は①課題を宣言②ゲーム③課題を実行できた回数を記録④次のゲームで1点だけ修正。勝敗だけで評価せず、課題を実行できた割合を見ます。よくあるミスは途中で課題を増やすこと。修正は1ゲーム1課題に固定します。

GUIDE / 16

得点パターン分析

得点した場面と失点した場面を、サービス・レシーブ・ラリーのどこで決まったかに分けて記録します。まず10点分を振り返り、得点につながったサービスやコースを2つ、失点につながったパターンを1つ選びます。コツは印象ではなく、実際の打球順とコースを書くこと。よくあるミスは「ミスした」で終わること。修正は、次の練習で再現できる行動に言い換えます。

GUIDE / 17

ミスの分類

ミスをネット、オーバー、左右のずれ、打点の遅れ、回転の読み違い、準備不足に分類します。動作順は①ミスの種類を一つ選ぶ②直前の打球と姿勢を確認③同じ状況を5球再現④修正後に5球打つ。コツは一度に複数の原因を直さないこと。よくあるミスはフォーム全体を変えること。修正は、打点や面の角度など一つの要素だけを変えて比較します。

GUIDE / 18

練習記録

練習後に「メニュー・回数・成功数・今日の課題・次回の修正」を短く記録します。成功数は感覚ではなく、10球中何球入ったかなど数えられる形にします。コツは長文にせず、次回の練習で見返せる一言を残すこと。よくあるミスは時間だけを書いて終わること。修正は、次回の最初のメニューを記録の最後に決めておきます。

GUIDE / 19

ダブルスの動きと声かけ

ダブルスで、打球後にパートナーの進路を空け、次の打球位置へ移る練習です。動作順は①サーブ・レシーブの役割を確認②交互に打つ③打球後に横へ抜ける④次の人が構える。コツは短い声かけで進路を共有すること。よくあるミスは打球後に同じ場所へ残ること。修正は球を使わず、交互に動く位置だけを先に確認します。
