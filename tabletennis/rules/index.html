GUIDE / 19
RULES IN REAL MATCHES / CASE STUDIES

試合で起きる場面からルールを覚える。

CASE 01 / サービス

トスが斜め前に流れた

状況：手のひらからボールを投げ上げたが、明らかに斜め前へ飛んだ。

判定：正しいサービスとはいえず、フォルトになる可能性がある。トスはほぼ垂直に上げ、相手から見える状態を保つ。

CASE 02 / エッジ

ボールが台の角に当たった

状況：ボールが台の上面の端（エッジ）に触れて相手コートへ入った。

判定：有効。台の上面の端はプレーイングサーフェスに含まれる。側面だけに当たった場合は有効なバウンドではない。

CASE 03 / ネットイン

ラリー中にネットに触れて入った

状況：サービスではなく、通常のラリー中の返球がネットに触れて相手コートへ入った。

判定：そのままプレー続行。ネットに触れたことだけでレットにはならない。

CASE 04 / ダブルス

同じペアの選手が連続で打った

状況：ダブルスでAペアの選手1が返球し、次も同じ選手1が打った。

判定：打球順序の違反。ダブルスはサーバー→レシーバー→サーバーのパートナー→レシーバーのパートナーの順で交互に打つ。

CASE 05 / サービスレット

正しいサービスがネットに触れた

状況：トス・打球など他の条件は正しく、サービスがネットに触れて相手コートへ入った。

判定：レットとなり、ポイントにせずサービスをやり直す。

CASE 06 / 16cm

トスが16cmに届かなかった

状況：手のひらから投げ上げた高さが16cm未満だった。

判定：サービスの要件を満たさない。少なくとも16cm、ほぼ垂直に投げ上げる必要がある。

判定の根拠：ITTF Statutes 2026（2026年1月1日施行版）。大会独自の運用や最新の改正がある場合は公式規則・大会要項を確認してください。
