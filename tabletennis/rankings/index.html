ランキング

男子シングルス

男子シングルスの順位は、ITTFが公表する週次ランキングで確認します。順位だけでなくポイント、前週からの変動、対象週を合わせて見ることが重要です。

GUIDE / 01

女子シングルス

女子シングルスもITTF公式の週次更新を基準に確認します。大会直後はポイント反映のタイミングに注意し、更新日が異なるデータを混ぜないようにします。

GUIDE / 02

男子・女子ダブルス

ダブルスはペア単位で順位が管理されます。ペアの組み替えや大会出場によってポイントが変わるため、選手個人のシングルス順位とは分けて確認します。

GUIDE / 03

混合ダブルス

混合ダブルスは男女1名ずつのペアで競う種目です。ペアの組み合わせごとにランキングが集計されるため、選手個人の順位と混同しないようにします。

02

ランキングの見方

ポイント制度

ランキングポイントは大会の格付けや成績などに応じて付与されます。詳細な算定条件や有効期間は制度変更の可能性があるため、最新のITTF規定を確認してください。

GUIDE / 06

順位変動

順位の上昇・下降は、新しい大会結果だけでなく過去ポイントの失効などでも起こります。単週の変動だけで実力の変化を断定しないことが大切です。

GUIDE / 07

ランキング対象大会

大会の種類や参加条件によってランキングへの反映方法が異なります。対象大会かどうかは、ITTFの最新ランキング規定と大会情報で確認します。

GUIDE / 08

公式発表の確認

ランキングを引用するときは、ITTF公式ページの対象週・種目・更新日を記録します。第三者サイトの表示は参考情報として扱い、公式順位と区別します.
