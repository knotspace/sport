ニュースカテゴリー

国際大会

WTT・ITTF・各大会主催者の発表を起点に、日程、ドロー、試合結果、優勝者などを整理します。大会名と発表日を確認し、速報と確定結果を区別します。

GUIDE / 01

選手・チーム

選手の移籍・所属・代表選考・引退・負傷など、競技活動に関わる発表を扱います。本人・チーム・協会の公式発信を優先し、未確認情報は掲載しません。

GUIDE / 02

用具・新製品

ラケット、ラバー、シューズなどの新製品情報をメーカー発表から確認します。発売日・価格・仕様は、確認できた項目と未公表の項目を分けて記載します。

GUIDE / 03

ルール・競技情報

競技規則の改定、大会方式、用具規定などの変更を扱います。適用開始時期と対象大会を確認し、競技者に影響する点をわかりやすく整理します。

GUIDE / 04
02

読み方・調べ方

公式発表を確認する

ニュースを読むときは、協会・大会主催者・メーカー・選手本人など、情報の発信元までたどれるかを確認します。SNSの転載だけで判断しないことが大切です。

GUIDE / 06

大会結果の見方

大会名、種目、ラウンド、対戦相手、ゲームカウントをセットで確認します。予選と本戦、団体戦と個人戦を混同しないように整理します。

GUIDE / 07

情報の更新日

日程・出場者・ランキングなど変わる情報には確認日を添えます。過去の記事を読む場合も、現在の情報と当時の情報を区別してください。

GUIDE / 08

出典・訂正ポリシー

記事では一次情報へのリンクを示し、事実と解説・見解を区別します。誤りが判明した場合は内容を確認して修正し、重要な訂正は読者に分かる形で示します.
