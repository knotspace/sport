卓球の技術

フォームの意味から、試合で使える応用技術まで。

技術は形をまねるだけでは身につきません。どこでボールをとらえ、どの方向へ力を伝え、次の動きへどうつなげるかを理解しましょう。

01

攻撃技術

フォアハンドドライブ

下半身の回転と体幹の動きを使い、ボールの後ろから上方向へスイングして前進回転をかける基本技術。打点を身体の前に置き、面の角度とスイング方向を調整します。

GUIDE / 01

バックハンドドライブ

身体の前でボールをとらえ、肘を支点に前腕と手首を連動させて回転をかけます。肘を身体から離しすぎず、打点とスイング幅を安定させることが大切です。

GUIDE / 02

スマッシュ

高く浮いたボールを、回転をかけるよりも前方向への力を中心に強く打ち抜く技術。打点を落としすぎず、相手コートの深さとコースを狙います。

GUIDE / 03

カウンター

相手のドライブに対して、下がりすぎず早い打点で返球する攻撃技術。相手の回転と球威を利用し、ラケット角度を合わせてコンパクトに振ります。

GUIDE / 04

ミート打ち

ボールを厚くとらえ、回転よりもスピードと安定した弾道を重視する打法。高いボールや回転の少ないボールに対して、面を安定させて前へ押し出します。

GUIDE / 05
02

台上・レシーブ

ツッツキ

下回転をかけながら台上のボールを低く返す技術。ラケットを上から下・前へ動かし、ボールの下側を薄くとらえて長さと回転を調整します。

GUIDE / 06

ストップ

相手の短いサービスやツッツキに対し、バウンド後に台から出にくい短い返球をする技術。力を抜き、バウンド直後を小さな動作でとらえます。

GUIDE / 07

フリック

台上の短いボールを先に攻撃する技術。肘を支点にコンパクトに振り、ボールの高さ・回転・コースに応じてミートまたは回転を加えます。

GUIDE / 08

チキータ

バックハンド側で台上の短いサービスを先に攻めるレシーブ技術です。右利きの場合は身体の左前で打点を取り、前腕と手首を連動させてボールの側面から斜め上を薄くとらえます。下回転には少し持ち上げる動きを加え、横回転には面の向きと打球方向を調整。最初は強く振らず、ネットを越える高さと短い準備動作を安定させましょう。

GUIDE / 09

流し・払うレシーブ

台上のボールを相手の空いたコースへ素早く送るレシーブです。流しはボールの横側をとらえて角度をつけ、払う動作は前方向への力を加えて速く返します。どちらも相手の回転を見てラケット面を調整し、打点を身体の前に置くことが基本。手首だけで急に振ると浮きやすいため、肘を支点に短く動かし、返球後はすぐ構えへ戻ります。

GUIDE / 10
03

サービス

下回転サービス

ボールの下側から後ろ側を薄くこすり、相手コートで低く弾む下回転を作るサービスです。右利きなら身体の右前で打点を取り、ラケットを下方向へ動かしながらボールの下部をとらえます。回転を強くするだけでなく、短い・長い・横回転を混ぜて相手の判断を難しくすることが重要。トスの高さ、打球位置、ボールを見せる動作など競技規則も守りましょう。

GUIDE / 11

横回転サービス

ボールの側面をこすり、左右へ曲がる回転を与えるサービスです。右利きではラケットを身体の内側から外側へ動かす形や、その逆の動きを使い分け、接触する位置で回転方向を調整します。回転だけでなく、ネット際に短く落とすか、エンドライン付近へ長く送るかも組み合わせます。相手に回転を読まれないよう、同じ構えからコースと長さを変える練習をしましょう。

GUIDE / 12

YGサービス

バックハンド側から、身体の前を横切るようなスイングで回転をかけるサービスです。右利きでは手首を使ってボールの側面から下側を薄くとらえ、横回転や横下回転を作ります。準備動作が独特になりやすいため、トスからインパクトまでのリズムを一定にし、打球後にすぐ戻れる姿勢を保つことが大切。最初は回転量よりも、狙ったコースへ安定して入れることを優先します。

GUIDE / 13

巻き込みサービス

フォア側からラケットを身体の内側へ巻き込むように動かし、ボールの側面や下側をこすって回転を作るサービスです。右利きでは手首と前腕の向きを調整し、横回転・横下回転・ナックルに近い球を打ち分けます。相手から見える準備をそろえたまま、接触位置とスイング方向を変えるのがポイント。短い球と長い球を混ぜ、3球目攻撃につながる配球を考えましょう。

GUIDE / 14

ナックルサービス

回転をほとんど与えず、相手に回転量を読み違えさせるサービスです。ボールを強くこすらず、厚めにとらえて前へ運びます。ただし完全な無回転にするのは難しく、少し回転が残ることもあります。下回転サービスと同じ構え・トス・スイングに見せて、インパクトだけを変えると効果的。相手が強く持ち上げようとして浮かせた球を、次の攻撃につなげます。

GUIDE / 15
04

守備・変化

ブロック

相手のドライブやスマッシュを、ラケット面を合わせて台上へ返す守備技術です。強く振り回すより、相手の球威と回転を利用し、バウンド直後から頂点付近の早い打点でコンパクトに合わせます。ラケット面は相手の回転に応じて調整し、深く返す・短く落とす・コースを変えるなど目的を決めます。返球後に身体が止まらないよう、足幅を保って次球へ備えましょう。

GUIDE / 16

カット

ボールの下側をこすり、強い下回転をかけて相手コートへ返す守備技術です。打点を身体の前から少し外側に置き、肩・前腕・体幹を連動させて斜め下方向へスイングします。相手のドライブの回転量に合わせてラケット面と振り幅を調整し、深さやコースも変化させます。腕だけで切ると浮いたりネットにかかったりするため、膝の曲げ伸ばしと打球後の戻りをセットで練習します。

GUIDE / 17

フィッシュ

中陣から後陣で、相手の強打を高めの弧線で返し、ラリーを続ける守備技術です。ボールを無理に強く打ち返さず、相手の回転に合わせて面を調整し、適度な上回転やナックル気味の返球を使い分けます。高く上げすぎるとスマッシュを受けやすいため、相手の打点や位置を見て高さと深さを変えることが重要。返球後は次の強打に備えて左右へ動ける位置へ戻ります。

GUIDE / 18

ロビング

相手の強打を高い弧線で返し、時間を作ってラリーを立て直す守備技術です。ラケットを下から上へ動かし、ボールの下側をとらえて高さと回転を調整します。単に高く上げるだけでは決められやすいため、相手の位置を見て深いコースへ送り、左右や回転量も変化させます。返球後は相手のスマッシュ方向を予測し、無理のない範囲で守備位置を整えましょう。

GUIDE / 19

粒高・アンチの基本

粒高やアンチラバーは、表面の摩擦や粒の倒れ方によって、相手の回転を受けたときの返球が変化しやすい用具です。ただし回転が自動的に反転するわけではなく、相手の回転量・ラケット角度・打球の厚さで結果が変わります。まずは同じボールをブロック・押し出し・ツッツキで返し、弾道と回転の違いを観察。変化だけに頼らず、コースとテンポを組み合わせることが大切です。

GUIDE / 20
TECHNIQUE LAB / VISUAL LEARNING

動きを、図で理解する。

フォアドライブの基本動作を、打点・スイング方向・体の使い方に分けて確認します。

① 構えと準備

膝を軽く曲げ、上体を少し前へ。右利きフォアなら右足側に体重を乗せすぎず、次に踏み込める幅を残します。

② インパクト

ボールが上がってくるタイミングを見て、体の前でとらえる。ラケット面を固定するだけでなく、回転量に合わせて角度を微調整します。

③ 振り抜きと戻り

振り切って終わりではありません。打球後はラケットを体の前へ戻し、相手の返球コースに合わせて小さく足を動かします。

よくあるミス

腕だけで振る／打点が体の横や後ろになる／打ったあとに直立する。まずは「低い姿勢・体の前の打点・打球後の戻り」を一つずつ確認しましょう。

05

応用ドライブ・攻撃

カウンタードライブ

相手の上回転を利用し、バウンド直後から頂点付近で前方向へ打ち返す攻撃。面を開きすぎず、相手の回転に合わせてスイング量を調整します。

GUIDE / 21

ループドライブ

下回転や低いボールに対して、薄くこすり上げて高い弧線と強い上回転を作る技術。膝を使って低い位置から入り、打球点を身体の前に置きます。

GUIDE / 22

スピードドライブ

相手の時間を奪うため、前方向への力を強めて低く速い球を打つドライブ。十分な高さがあるボールを選び、打点を落としすぎないことが大切です。

GUIDE / 23

バックハンドカウンター

相手の上回転に対し、バウンド直後から頂点前を狙い、身体の前でコンパクトに打ち返す技術です。肘を支点に前へ短く振り、相手の回転が強いほど振り幅を小さくして面の角度を優先します。

GUIDE / 24

フォアハンドカウンター

フォア側へ来た上回転球を、下がらず早い打点で前方向へ返す技術です。足を先にボールの後ろへ運び、体幹の小さな回転と前腕を連動。大振りせず、相手のコースへ合わせて安定させます。

GUIDE / 25

フォアハンドスマッシュ

高く浮いたボールをフォア側で決める打法です。打球点の後ろへ足を運び、体の回転と前腕を合わせて前へ振り抜きます。力任せに下へ叩かず、ネット上の余裕とコースを確保しましょう。

GUIDE / 26

ドライブブロック

相手の強打に対し、受け身で止めるだけでなく前方向へ小さく振って返す技術。打球点を早めにし、面の角度を安定させます。

GUIDE / 27

カウンタースマッシュ

相手の強い攻撃を高い打点で打ち返す技術。準備が遅れるとミスが増えるため、相手のスイングを見て早く位置取りします。

GUIDE / 28
06

応用レシーブ・サービス

バックハンド台上ドライブ

台上のやや長い下回転球を、バック側で早くとらえて上回転を加える技術です。身体を台に近づけすぎず、肘を前に出して低い位置から前上方向へ小さく振ります。短い球は無理に打たず、ストップやツッツキと使い分けます。

GUIDE / 29

逆チキータ

ボールの反対側をこするようにとらえ、通常のチキータとは異なる横回転を加える技術。手首だけに頼らず、打球方向と回転方向を分けて練習します。

GUIDE / 30

バックハンドプッシュ

バック側の短い下回転球を、ラケット面を少し開いてボールの下後ろから前へ押し出す台上技術です。手首だけでこねず、肘を前に運び、返球を低く短く保ってから構えへ戻ります。

GUIDE / 31

バックハンドフリック

バック側の短いボールを、身体の前でコンパクトに弾く技術。ラケット面を保ち、ボールの高さと回転に応じて角度を調整します。

GUIDE / 32

フォアフリック

フォア側の短いボールを台上で攻める技術。右利きの場合は右足を台の下へ入れ、打球後すぐに戻れる姿勢を保ちます。

GUIDE / 33

ストップレシーブ

相手の短いサービスを、ネット際に短く返して攻撃を防ぐ技術。ボールの勢いを吸収し、バウンド直後の低い位置で柔らかく触ります。

GUIDE / 34

ツッツキレシーブ

下回転サービスを中心に、ボールの下側を薄くとらえて低く返す技術。ラケット面を開き、押しすぎず回転量を調整します。

GUIDE / 35

ロングツッツキ

相手コートの深い位置へ長く返すツッツキ。相手のバック深くやミドルを狙い、浮かない高さと長さを両立させます。

GUIDE / 36

ハーフロングサービス

2バウンド目がエンドライン付近になる長さを狙うサービス。短いと思わせてから台の奥へ伸ばし、相手の判断を難しくします。

GUIDE / 37

逆横回転サービス

通常の横回転サービスとは反対側を薄くとらえ、逆向きの横回転を作るサービスです。接触位置とスイング方向を少しずつ変え、相手コートでのバウンドと曲がり方を見て回転を確認します。トスを隠さず、規則に沿った打球動作を守りましょう。

GUIDE / 38

横下回転サービス

ボールの横下をこすり、横回転と下回転を組み合わせるサービス。回転方向を一定にし、相手のラケット角度をずらすことを狙います。

GUIDE / 39

横上回転サービス

ボールの横上をこすり、横回転と上回転を組み合わせるサービス。下回転サービスと同じ構えから出すと、相手の判断を遅らせやすくなります。

GUIDE / 40

バックハンドサービス

バックハンド側の構えから出すサービスです。身体の前でボールをとらえ、前腕と手首の小さな動きで下回転・横回転・ナックル系を打ち分けます。まずは同じトスと構えで長さを安定させ、打球後すぐに戻れる姿勢を作ります。

GUIDE / 41

フォアハンドロングサービス

フォア側から相手コートの深い位置へ速く送るサービスです。ボールの後ろ側を厚めにとらえて前方向へ振り、低い弾道でバック深くやミドルを狙います。速さだけでなく、短いサービスとの組み合わせで相手の位置取りを揺さぶります。

GUIDE / 42

ナックルロングサービス

回転を少なくした長いサービスで、相手に強い下回転だと思わせないことを狙います。こすりすぎずボールの後ろを厚くとらえ、エンドライン付近へ低く送ります。完全な無回転とは限らないため、実際のバウンドで回転を確かめます。

GUIDE / 43

ロングサービス

相手コートの深い位置へ速く送るサービス。相手の準備が整う前を狙い、フォア・バック・ミドルへコースを散らします。

GUIDE / 44

しゃがみ込みサービス

低い姿勢から身体の回転を使って回転を加えるサービス。無理な姿勢で腰や膝を痛めないよう、安定したフォームから練習します。

GUIDE / 45
07

守備・変化の応用

カットブロック

相手のドライブに対して、ラケットを少し下方向へ動かし下回転を加えて返すブロック。相手の回転量を見て面と動きを調整します。

GUIDE / 46

ショートブロック

相手の強打を利用し、台の近くで短く抑えて返すブロック。ラケットを大きく振らず、ボールの勢いを吸収する感覚を身につけます。

GUIDE / 47

ロングブロック

ブロックを相手コートの深い位置へ返し、相手に再び動かせる技術。面を安定させ、相手の打球コースに合わせて位置を調整します。

GUIDE / 48

サイドスピンカット

下回転に横回転を組み合わせ、相手コートで横へ変化するカットです。ボールの斜め下側をとらえ、ラケット面とスイング方向を調整します。曲がりだけに頼らず、深さと左右のコースを変えて相手の打点をずらします。

GUIDE / 49

サイドスピンロビング

高い弧線のロビングに横回転を加え、相手のスマッシュ後のバウンドを変化させる守備技術です。ボールの下側から斜め横へこすり、十分な高さと深さを確保。回転をかけることより、まず相手コートへ安全に返すことを優先します。

GUIDE / 50
08

カット・ブロック応用

アクティブブロック

相手のドライブを受け止めるだけでなく、バウンド直後に前方向へ小さく押し返すブロックです。肘を身体の前に保ち、相手の回転が強いときは面を少し閉じて振り幅を抑えます。

GUIDE / 51

サイドスピンブロック

ブロックの接触時にボールの側面を薄くとらえ、横回転を加えて返球する技術です。ラケット面を大きく動かすと浮きやすいため、まずは短い接触で回転方向とコースを安定させます。

GUIDE / 52

ミドルブロック

相手の利き腕の肘付近を狙い、フォアとバックの切り替えを遅らせるブロックです。大きく振らず、相手の打球方向を見て面を合わせ、深さを一定に保つ練習から始めます。

GUIDE / 53

ナックルブロック

強くこすらずボールをやや厚くとらえ、回転の少ない返球を作るブロックです。下回転系のブロックと同じ準備動作を保ち、接触の厚さだけを変えると変化を隠しやすくなります。

GUIDE / 54

ロングカット

台から距離を取って、相手コートの深い位置へ下回転を送るカットです。ボールの斜め下後ろを薄くとらえ、弧線を確保しながらエンドライン付近へ返します。深さが足りないと相手の強打を招くため、まずは安定した長さを優先します。

GUIDE / 55

ショートカット

相手の前陣に短く落とすカットです。台に近づいて打点を早めに取り、ボールの下側を柔らかくとらえて前への押し出しを抑えます。短くしようとしてネットにかけないよう、回転と高さの両方を調整します。

GUIDE / 56

ナックルカット

通常の強い下回転カットよりも厚めに接触し、回転を少なくして返す変化技術です。フォームを大きく変えず、接触の厚さを変えて相手に回転量を読ませにくくします。完全な無回転とは限らないため、実際のバウンドを確認しましょう。

GUIDE / 57

カット打ち

下回転のボールを攻撃するときは、ラケット面をやや開き、ボールの後ろ下から前上方向へスイングします。回転が強いほど上方向の成分を増やし、最初は深いコースへ高めの弧線で入れることを優先します。

GUIDE / 58

カットマンの反撃ドライブ

相手の返球が長く浮いた瞬間に、前へ入ってドライブで反撃する技術です。カットの構えから急に大振りせず、足を先にボールの後ろへ運び、打球後はすぐ守備位置へ戻ります。

GUIDE / 59

カットからの前陣カウンター

後ろでカットを続けるだけでなく、相手の甘い返球に合わせて台の近くへ入り、早い打点でブロックやカウンターへ切り替えます。前へ入るタイミングを決めておき、無理な距離移動を避けます。

GUIDE / 60
09

フットワーク・連続攻撃

連続ドライブ

1本目を打ったあとに腕を止めず、次のボールに備えて重心を戻しながら連続してドライブする技術です。毎回フルスイングせず、打点・戻り・次の準備を同じリズムで繰り返します。

GUIDE / 61

ドライブからスマッシュへの切り替え

最初の下回転球はドライブで持ち上げ、次に高く返ってきた球をスマッシュで決める連続攻撃です。1本目の直後に前へ突っ込みすぎず、相手の返球を見て打点へ入り直します。

GUIDE / 62

フォア回り込み

バック側へ来たボールに対して、身体を移動させてフォアハンドで打つフットワークです。右利きは右足を軸に左足を運び、打球点の後ろへ入ってから振ります。回り込み後のバック側が空くため、打球後の戻りもセットで練習します。

GUIDE / 63

2点フットワーク

バック側とフォア側の2か所へ交互に送られたボールを処理する基本練習です。相手の打球前に小さくスプリットステップを入れ、移動後は両足をそろえず、次へ動ける幅で止まります。

GUIDE / 64

3点フットワーク

バック・ミドル・フォアの3か所を順番に動いて打つ練習です。最初は決めた順番で小さく動き、慣れたら順番をランダムにします。腕だけで届かせず、足で打点の後ろへ入ることが大切です。

GUIDE / 65

前後フットワーク

短いボールと深いボールを交互に処理する動きです。短球には一歩目を素早く出して身体を台へ近づけ、深球には細かい戻り足で距離を作ります。上体だけを倒して届かせないようにします。

GUIDE / 66

クロスステップ

左右に大きく離れたボールへ移動するとき、足を交差させて移動距離を確保するステップです。近い距離では小刻みなサイドステップを使い、遠い距離だけクロスステップへ切り替えます。

GUIDE / 67

ミドル処理

身体の正面や利き腕の肘付近へ来たボールを、フォアかバックのどちらで打つか素早く決める技術です。相手の打球前に構えを小さくし、肘を身体から少し離して窮屈な詰まりを防ぎます。

GUIDE / 68

打球後の戻り足

打った直後に次の球へ備え、重心を基本位置へ戻す動作です。打球後に前足へ体重を残しすぎず、床を押して小さく戻り、相手が打つ前に再び構えを作ります。

GUIDE / 69

台上からの戻り

ストップやフリックなど台上処理のあと、前へ出た身体を次のラリーに備えて戻す動作です。打球後に足を止めず、台から一歩分の距離を取りながら重心を整え、相手の次球を待ちます。

GUIDE / 70

台上バックフリック

バック側の短いボールを、手首だけで弾かず前腕と体幹を小さく連動させて払う技術です。打球点を頂点付近に置き、面を少し前へ向けて短く振り抜くと、浮き球になりにくくなります。

GUIDE / 71

フォアフリック

フォア前の短いボールを、身体を台へ近づけて前方向へ払う技術です。肘を先に運び、打球直前にラケット角度を決めて、手首を使いすぎないようにします。

GUIDE / 72

チキータの初動

バック側の短い下回転・横回転に対して、ラケットを身体の前へ入れて回転をかけるレシーブです。膝を曲げて打球点へ近づき、肘を支点に前腕をコンパクトに回す準備を早くします。

GUIDE / 73

逆チキータ

ボールの外側を薄く捉え、相手の回転と逆方向の横回転を加えるバック系レシーブです。ラケット面を急に返さず、ボールの側面を擦る方向を一定にして、まずはコースより回転の再現性を優先します。

GUIDE / 74

ストップの長短調整

相手コートで2バウンドしやすい短さに抑える台上技術です。強く握らず、バウンド直後の勢いを吸収し、打球後にラケットを止めることで長くなりすぎるのを防ぎます。

GUIDE / 75

ツッツキの深さ調整

相手コートのエンドライン付近へ低く深く送るための技術です。ボールの下を薄く捉え、前へ押す距離を少し長くし、ネット上の高さを一定に保ちます。

GUIDE / 76

横回転ツッツキ

下回転に横回転を混ぜて、相手のラケット角度をずらす台上技術です。ボールの下側だけでなく側面も薄く擦り、面の向きとスイング方向を分けて意識します。

GUIDE / 77

ナックルツッツキ

回転量を抑えて相手のオーバーミスや持ち上げすぎを誘うツッツキです。切る動作を大きく見せても、インパクトではボールを厚く捉え、ラケットを急に加速させないことがポイントです。

GUIDE / 78

下回転サーブの切り分け

強い下回転と弱い下回転を同じフォームから出し分ける技術です。スイング全体を変えるより、インパクトの薄さと接触時間を調整し、バウンド後の戻り方で回転差を確認します。

GUIDE / 79

横下回転サーブ

横回転と下回転を同時に与え、相手のレシーブ角度を限定するサーブです。ボールの斜め下側を擦り、身体の向きで回転方向を隠しすぎず、狙ったコースへ安定して出します。

GUIDE / 80

横上回転サーブ

横回転に上回転を混ぜ、相手が下回転と読み違えると浮きやすいサーブです。ボールの斜め上側を薄く擦り、バウンド後に前へ伸びる軌道を確認して回転を調整します。

GUIDE / 81

ナックルサーブ

回転を極力抑え、相手に回転量を読み違えさせるサーブです。ボールを厚く当てる感覚を身につけ、切るサーブと同じトス・構えから出してフォームの差を小さくします。

GUIDE / 82

フォア前サーブ

フォア前の短い位置へ低く落とすサーブです。第1バウンドを自分側のエンドライン近くに置き、ネットを越える高さを抑えながら第2バウンドが相手コート前方になる長さを調整します。

GUIDE / 83

バック前サーブ

バック側から相手のフォア前・バック前を狙うサーブです。身体の正面で打球せず、ボールの横を擦るスペースを確保し、同じトスから左右へコースを変えます。

GUIDE / 84

巻き込みサーブ

フォア側から腕を巻き込むように振り、横回転や横下回転を出すサーブです。肘の位置を安定させ、手首だけを急に返さず、ボールの側面を薄く捉える感覚をつかみます。

GUIDE / 85

YGサーブ

身体の外側から内側へ振る動きで、相手から見た回転方向を読みづらくするサーブです。最初は回転量よりインパクト位置を一定にし、トスと打球点を毎回そろえてから変化を増やします。

GUIDE / 86

サーブの第2バウンド位置

短いサーブか長いサーブかを決める重要な目安です。相手コートの第2バウンドがエンドラインより手前に落ちるか、台から出るかを練習で確認し、狙いごとに第1バウンド位置を調整します。

GUIDE / 87

サーブの合法な隠し方

相手から見えにくくする工夫と、ルールに反する隠蔽は区別が必要です。トス後のボールを身体や腕で隠さず、フリーハンドをどけてインパクトを見せたまま、構えやコースで判断を難しくします。

GUIDE / 88

レシーブの構え

相手のサーブに対して、フォア・バックのどちらにも動ける姿勢を作る準備です。足幅を肩幅より少し広くし、かかとを固めず、ラケットを身体の前に置いて相手のトスを見ます。

GUIDE / 89

レシーブの回転判断

サーブの回転を、ラケットの接触方向・相手の手首・バウンド後の変化から判断します。最初から球種を断定せず、短い下回転には面を開き、上回転には面をかぶせる基本から調整します。

GUIDE / 90

レシーブの長さ予測

サーブが短いか長いかを、相手コートでの第1バウンドとボールの伸びから早く判断する技術です。バウンド直後に前後移動を決め、台の上へ身体を突っ込みすぎないようにします。

GUIDE / 91

レシーブのコース選択

回転だけでなく相手の戻り位置を見て、クロス・ストレート・ミドルを選ぶ技術です。強打できない球は深く安全に返し、甘い球だけ相手の空いた場所へ先に動かします。

GUIDE / 92

3球目攻撃の準備

サーブの次に返ってくるボールを攻撃するため、サーブ直後から足とラケットを整える戦術です。サーブを出したあとに見送らず、返球コースを予測して小さく戻り、打球点へ先に入ります。

GUIDE / 93

4球目攻撃の準備

レシーブ後の相手の3球目を予測し、次の4球目で主導権を取る準備です。返球後に身体を止めず、相手のラケット角度と自分の返球コースから次球の方向を絞ります。

GUIDE / 94

ブロックの面角度

相手のドライブを台に収めるため、ラケット面をボールの回転と速度に合わせて調整する技術です。強い上回転には面を少しかぶせ、打球点を身体の前に置いてコンパクトに合わせます。

GUIDE / 95

アクティブブロック

相手の強打を受けるだけでなく、前方向へ少し押して速い返球にするブロックです。大きく振らず、ボールの頂点付近で前腕を短く使い、相手の打球速度を利用します。

GUIDE / 96

前陣カウンター

台に近い位置で相手のドライブを早い打球点で返す技術です。バックスイングを小さくし、相手のボールが上がりきる前に面を合わせて、コースを先に決めます。

GUIDE / 97

カウンターループ

相手の上回転ドライブに対して、自分も回転をかけて打ち返す技術です。相手の回転を利用しながら、打球点を落としすぎず、身体の回転と前腕の加速を連動させます。

GUIDE / 98

ミート打ち

回転を強くかけず、ボールを厚く捉えて直線的に打つ技術です。高く浮いた球やナックル性の球に使いやすく、ラケット面を安定させて前へ押し出します。

GUIDE / 99

スマッシュ

高く浮いたボールを強く打ち抜く決定打です。打球点の少し後ろへ身体を入れ、ラケットを高く構えすぎず、ボールの頂点から落ち始める位置で厚く捉えます。

GUIDE / 100

ループドライブ

強い上回転をかけて弧線を高くし、安定して相手コートへ入れるドライブです。ボールの下側を薄く擦り、膝から上へ力を伝えて、ネットを越える高さを確保します。

GUIDE / 101

スピードドライブ

弧線を低く抑え、前方向への速度を重視するドライブです。打球点を頂点付近に置き、ボールを厚めに捉えて、上方向へ振りすぎないようにします。

GUIDE / 102

フォアドライブの体重移動

後ろ足から前足へ重心を移しながら、腰と肩を回してボールへ力を伝える動作です。腕だけで振らず、打球後に前足へ体重が流れすぎないように戻り足も準備します。

GUIDE / 103

バックドライブの肘支点

肘を身体の前に置き、前腕を回して上回転をかけるバックハンド技術です。肘を固定しすぎず、肩が上がらない範囲で前腕を加速させ、打球後はすぐ基本姿勢へ戻します。

GUIDE / 104

ブロックから攻撃への切替

相手の強打をブロックしたあと、浮いた返球や甘い球を自分から攻める連続技術です。ブロック後にラケットを下げず、相手の体勢が崩れたら一歩前へ入り攻撃へ切り替えます。

GUIDE / 105

カット打ち

下回転の強いカットボールを、回転量に合わせて持ち上げる攻撃技術です。ボールの下側を擦って弧線を作り、無理に一発で決めず、深さとコースで次の攻撃につなげます。

GUIDE / 106

カットの変化

同じフォームから強い下回転と弱い下回転、ナックルを使い分ける守備技術です。インパクトの薄さとラケットの移動量を変え、相手の打球がネットにかかるか浮くかを観察します。

GUIDE / 107

粒高の変化

粒高ラバーで相手の回転を利用し、返球の回転や弾道を変える技術です。自分から強く振るより、相手の回転方向と接触角度を理解し、面を少しずつ変えて変化を作ります。

GUIDE / 108

粒高プッシュ

粒高ラバーでボールを前へ押し、低く速い返球を送る技術です。ラケット面を安定させて打球点を早めに取り、押す距離を短くして浮き球を防ぎます。

GUIDE / 109

粒高ブロック

相手のドライブを粒高ラバーで受け、回転の影響を抑えたり変化をつけたりする技術です。面を急に動かさず、ボールの勢いを吸収するか前へ押すかを決めてから合わせます。

GUIDE / 110

カットマンの攻撃

守備中心のラリーから、甘いボールを見逃さずドライブやスマッシュで攻める技術です。相手の打球が浅くなったら前へ入り、守備姿勢から攻撃姿勢へ重心を切り替えます。

GUIDE / 111

ロビング

台から大きく離れ、高い弧線で相手コートへ返す守備技術です。相手のスマッシュに対して打球点を後ろで確保し、深さと高さを変えて相手の連続攻撃を崩します。

GUIDE / 112

フィッシュ

台から少し離れた位置で、相手の強打を低く返してラリーを続ける守備技術です。ボールの勢いを利用してコンパクトに合わせ、無理に強く振らず深いコースを狙います。

GUIDE / 113

台から下がったときの距離調整

後陣ではボールの到達時間が長くなるため、打球点と身体の距離を一定に保つことが重要です。下がりすぎて頂点を逃さず、ボールの落下に合わせて一歩前へ入る選択も使います。

GUIDE / 114

左右フットワークの切替

フォアとバックへ連続して動くとき、移動幅に応じてサイドステップとクロスステップを使い分けます。小さな移動で足を交差させず、大きな移動では最後の一歩で打球姿勢を作ります。

GUIDE / 115

2点フットワーク

フォアとバックの2か所へ交互に送られるボールを打つ基本練習です。移動の速さだけでなく、打球後に基本位置へ戻る距離を一定にして、次の一歩を遅らせないようにします。

GUIDE / 116

不規則フットワーク

コースが予測できない球に対し、反応して移動しながら打球姿勢を作る練習です。最初の一歩を小さく速く出し、打球直前に細かい調整歩を入れて身体の正面で捉えます。

GUIDE / 117

重心の上下動

打球時に膝を使って高さを合わせ、身体が上下に大きく揺れないようにする技術です。膝を曲げたまま移動し、打球の瞬間だけ伸び上がらず、次の球へつながる高さを保ちます。

GUIDE / 118

ラリー中の視線

相手のラケットとボールを見ながら、打球後は相手の準備位置も確認する視線の使い方です。ボールだけを追い続けず、インパクトの直前に相手の面の向きを捉える習慣をつけます。

GUIDE / 119

ポイント間ルーティン

得点後に呼吸・用具・次の作戦を短く整える習慣です。毎回同じ順番で呼吸を整え、直前の失点を引きずらず、次の1本で狙うコースを一つだけ決めます。
