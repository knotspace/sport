技術用語

ドライブ

ボールに前進回転をかけて攻撃する打法。ボールの後ろから上方向へこすり、弧線を作りながら相手コートへ入れます。

GUIDE / 01

ミート

ラケット面でボールを厚くとらえ、回転よりもスピードを重視して打つこと。高いボールや回転の少ないボールを攻めるときに使います。

GUIDE / 02

ブロック

相手の攻撃を大きく振らずに受け止めて返球する技術。ラケット角度と打球点を調整し、安定性やコースの変化を作ります。

GUIDE / 03

カット

ボールに強い下回転をかけて返球する守備技術。相手のドライブの回転とスピードに合わせ、打球点やラケット角度を調整します。

GUIDE / 04

チキータ

バックハンドで台上のボールに横回転系の回転をかけて攻撃するレシーブ技術。ボールの横側をとらえ、短いサービスにも先手を取ります。

回転・球質

上回転

ボールが進む方向へ前向きに回転すること。バウンド後に前へ伸びやすく、ラケット面を上向きにしすぎるとオーバーしやすくなります。

GUIDE / 06

下回転

ボールの進行方向と逆向きに回転すること。バウンド後に失速しやすく、強く打つにはラケットを下から上へ動かして持ち上げます。

GUIDE / 07

横回転

ボールに左右方向の回転を与えること。バウンド後や相手ラケットに当たった後に横へ曲がるため、回転方向を見て面を調整します.
